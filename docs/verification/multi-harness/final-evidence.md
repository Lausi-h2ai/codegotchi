# Final real-CLI evidence (2026-10-08)

Screenshot links in this index refer to local generated files, which are ignored
by Git along with raw logs. The result JSON, inspection notes/hashes, and this
index are tracked; the original captures remain on the audit machine.

All four genuine CLIs ran through the installed release launcher, with real xterm keyboard/pointer events and scripted loopback models. Every linked layout/state sheet was opened and manually inspected. Behavioral passing does not mean the images are defect-free: see the [current ledger](../multi-harness.md) and [inspection notes](final-inspection.json).

Each layouts sheet contains Full 120×45, Compact 100×30, Minimal 80×21, and Narrow 64×45 edited composers. Each states sheet contains edited input, response, history, Strict denial, care, and keyboard after care (six cells). This is 80 sheets / 400 cells.
